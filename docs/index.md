# FDOx Squirrel

Documentation for [fdo-squirrel](https://github.com/FDOx-squirrel/fdo-squirrel),
which turns a package with `CITATION.cff` and `MD.cff` into FAIR Digital Object
metadata (RDF), an RO-Crate and a FAIR Signposting landing page.

- [Validating the RO-Crate in a bundle](validate-ro-crate.md): step by step,
  with `roc-validator`.
- [FDOx profile of RO-Crate](ro-crate-profile.md): what the crate declares and
  how it was validated.
- [How the metadata is mapped to RO-Crate](ro-crate-mapping.md).
- [FAIR Signposting](signposting.md): landing page, linkset, what Zenodo serves.
- Release notes: [v1.3.0](releases/v1.3.0.md), [v1.2.1](releases/v1.2.1.md), [v1.2.0](releases/v1.2.0.md),
  [v1.1.0](releases/v1.1.0.md).

Source code, issues and the full README:
<https://github.com/FDOx-squirrel/fdo-squirrel>.
