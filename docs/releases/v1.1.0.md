## fdo-squirrel v1.1.0 — RO-Crate export and FAIR Signposting

Every finished bundle now carries an `ro-crate-metadata.json` at its root,
making the bundle an RO-Crate 1.2, and a landing page with FAIR Signposting
links, making it a lightweight Webby FDO on static hosting.

- New `fdo_rocrate.py`: RO-Crate 1.2 view generated from the same inputs as
  `fdo-metadata.ttl`; creators, licence and file facts come from shared
  helpers, so both outputs agree. Deterministic, standard library only.
  Declares the new FDOx RO-Crate profile (`docs/ro-crate-profile.md`);
  mapping and scope in `docs/ro-crate-mapping.md`.
- New `fdo_signposting.py`: `fdo-landing-page.html` with `<link>` signposts
  (`cite-as`, `describedby`, `item`, `license`, `author`, `type`); with the
  new `--base-url` option, absolute links plus an RFC 9264 linkset
  `fdo-linkset.json` (Level 2). See `docs/signposting.md`.
- New `tools/check_signposting.py` reports what a URL (or a local landing
  page) actually serves, including whether a RO-Crate is retrievable via
  Signposting.
- `fdo-metadata.ttl` lists the new files as `dcat:Distribution` entries.
- First offline tests: `python -m unittest discover -s tests`.
- Backwards compatible: existing outputs unchanged apart from the added
  files and their distribution entries.
