## fdo-squirrel v1.2.1 — fix for the "MD.cff, filled out" graph

`fdo_md_cff_graph.svg` / `.png` in the bundle (and in `_work/`) drew the
central `MD_cff` node far too tall whenever the `description` was long: its
height was computed from every wrapped description line, while only one
truncated line is drawn. The node is now as tall as its number of fields,
and the arrows end spread along its edge instead of piling up in one point.

- Only that one graphic changes; the RDF, the RO-Crate and everything else in
  the bundle are unchanged (apart from the version string).
- New test `tests/test_md_cff_graph.py`.
